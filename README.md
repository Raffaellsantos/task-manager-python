# Task Manager (Python)

Projeto de gerenciamento de tarefas via terminal.

## 🚀 Funcionalidades
- Adicionar tarefas
- Listar tarefas
- Atualizar nome e status
- Remover tarefas

## 🛠 Tecnologias
- Python
- Sqlite

## 📌 Objetivo
Projeto criado para praticar lógica de programação e manipulação de dados.

## ▶ Como rodar
```bash
python main.py
